# Shams — Fire Protection & MEP (static site, no build step)

Pages: index (Home) · services · products · projects · about · contact

- js/data/site.js — phone / email / WhatsApp / address (empty = hidden). Fill these in. The contact form sends via mailto to `email`.
- js/data/services.js, products.js, partners.js, clients.js — content of each page.
- js/data/projects.js — add real projects; a "Featured projects" section then appears on projects.html.
- css/style.css — colour tokens at the top (from the company profile).
- assets/ — logo, partner and client logos, product photos (extracted from the profile PDF).

Open index.html directly or serve the folder with any static server.
